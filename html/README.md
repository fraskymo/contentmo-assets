# ContentMo HTML Archive

This directory preserves ContentMo email and Squarespace webpage HTML by campaign date. Campaign folders contain the final version at the top level. Earlier versions are retained in a `revisions` folder.

## Naming conventions

- `email.html`, `author-promo-email.html`, or `reader-newsletter.html`: EmailOctopus-ready email HTML.
- `webpage.html`: complete Squarespace webpage HTML.
- `webpage-fragment.html`: HTML intended for a Squarespace code block rather than a complete document.
- `revisions/*-v1.html`: an earlier version preserved for reference.
